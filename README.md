# GBT 模拟交易看板

本地优先的**模拟交易**展示页。页面上全部金额、收益、成交与曲线均为**演示数据**，不是真实业绩，不可用于投资决策。

## 打开方式

- 双击仓库中的 `index.html`（`file://` 即可本地打开）
- 或在本目录启动任意静态服务器后用浏览器打开（可选）

自包含单页：内嵌 CSS / JS / SVG，无 CDN、无外部请求。

## 功能概览

- 六角色流程：扫描 → 风险检查 → 仓位计算 → 模拟执行 → 日志 → 资金统计
- 本地演示控制：继续 / 暂停、单步推进、重置（默认暂停）
- 虚拟标的：`DEMO-A` / `DEMO-B` / `DEMO-C`（标注为虚拟，不是真实证券）
- 演示账本示例：起始 `1000.00` + 模拟盈亏 `180.00` = 当前 `1180.00`（收益率 `+18%`）

## 硬边界

- **模拟交易 · 全部为演示数据 · 非真实业绩**
- 不接实盘、不接资金、不接行情
- 不选定交易市场或行情供应商
- 产品名「GBT 模拟交易看板」，非官方 Grok 产品
